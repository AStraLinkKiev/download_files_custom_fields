# Product Files for JoomShopping

Пакет `pkg_prodfiles` додає до Joomla компонент керування файлами товарів і плагін інтеграції з JoomShopping. Основна ідея: файли створюються в одному адміністративному розділі, а в картці товару JoomShopping менеджер тільки вибирає потрібні файли та задає порядок їх виводу.

## Склад пакета

- `com_prodfiles` - адміністративний компонент для створення та редагування файлів.
- `plg_jshopping_prodfiles` - плагін JoomShopping, який додає вкладку/блок вибору файлів у картку товару.
- `pkg_prodfiles` - інсталяційний пакет, який встановлює компонент і плагін разом.

Готовий архів для встановлення:

```text
pkg_prodfiles_custom_fields.zip
```

## Вимоги

- Joomla 6.1.0 або сумісна версія.
- JoomShopping 5.0.0 або новіший.

Під час встановлення `pkg` перевіряє наявність `com_jshopping` і його версію. Якщо JoomShopping не встановлений або версія нижча за `5.0.0`, встановлення пакета зупиняється з повідомленням про помилку.

## Функціонал

### Керування файлами

У компоненті `com_prodfiles` можна створювати список файлів, які потім будуть доступні для прив'язки до товарів JoomShopping.

Для кожного файлу підтримуються стандартні поля:

- назва;
- опис;
- файл/посилання для завантаження;
- додаткові кастомні поля.

### Кастомні поля

У налаштуваннях компонента можна задати додаткові поля для введення інформації про файл. Це дозволяє використовувати один компонент у різних проєктах з різними вимогами до метаданих.

Підтримуються два формати налаштування.

Простий формат:

```text
Версія
Тип документа
Примітки
```

Розширений формат:

```text
key|Назва|type|show_on_site
```

Приклад:

```text
version|Версія|text|1
manual_url|Посилання на інструкцію|url|1
internal_note|Внутрішня примітка|textarea|0
```

Підтримувані типи:

- `text`
- `textarea`
- `url`
- `email`
- `number`
- `date`

Параметр `show_on_site` визначає, чи показувати поле у фронтальній частині сайту:

- `1` - показувати;
- `0` - не показувати.

Значення кастомних полів зберігаються окремо для кожного файлу.

### Інтеграція з товаром JoomShopping

Плагін додає в адміністративну картку товару JoomShopping можливість:

- вибрати доступні файли зі списку;
- задати порядок файлів для конкретного товару;
- зберегти прив'язку файлів без повторного завантаження файлу в кожному товарі.

Порядок, заданий у картці товару, використовується для виводу файлів у фронтальній частині.

### Фронтальна частина

Компонент має фронтальне представлення для виводу файлів, пов'язаних з товарами. У виводі можуть використовуватися стандартні поля та кастомні поля, для яких у налаштуваннях увімкнено показ на сайті.

## Встановлення

1. У Joomla перейти в `System -> Install -> Extensions`.
2. Завантажити архів `pkg_prodfiles_custom_fields.zip`.
3. Переконатися, що компонент `com_prodfiles` і плагін `plg_jshopping_prodfiles` встановлені.
4. Увімкнути плагін JoomShopping, якщо він не був увімкнений автоматично.

## Структура репозиторію

```text
bridge_plugin_prodfiles/        source плагіна JoomShopping
com_prodfiles/                  source компонента Joomla
pkg_prodfiles/                  source інсталяційного пакета
pkg_prodfiles_custom_fields.zip готовий пакет для встановлення
```

## Примітки для розробки

Після змін у компоненті або плагіні потрібно перезібрати відповідні zip-архіви всередині `pkg_prodfiles`, а потім перезібрати фінальний `pkg_prodfiles_custom_fields.zip`.
